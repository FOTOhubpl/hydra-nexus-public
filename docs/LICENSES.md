This answers NASK task §4: libraries, models and external services with licences and usage limits.

## Scope: four different kinds of rights

This file separates four things that are often mixed up:

1. **Library licences** (Python and UI packages, system packages): what may be done with the code we run and ship in the image.
2. **Model weight licences** (`models.lock.json`): set by the weight publisher, independent of the licence of the library that loads them.
3. **Dataset and service terms** (CERT Polska list, PhishTank, PhiUSIIL, RDAP registries, crt.sh, Team Cymru, Meta Ad Library, Amazon Bedrock): conditions on queries, attribution and reuse of the answers.
4. **Rights to ad content**: the creatives, pages and texts inside the organiser material and inside public feeds belong to third parties. A permissive licence of a dataset card (CC BY, MIT) does not by itself grant the right to redistribute every image or page in it. Organiser material is used only for this challenge and never published (task §8); public-corpus results are shown as aggregates and public indicators.

Copyleft is not automatically a problem: file-level copyleft (MPL-2.0) used unmodified, and GPL programs run as separate processes or servers (ffmpeg, Neo4j Community in an optional container) do not place HYDRA's own code under their licence. They are listed below so the jury and NASK can check that reading.

## External datasets (offline, not shipped; details in docs/datasets/EXTERNAL.md)

Brand labels in these datasets are group-level, not campaign truth. External data is separated from organiser data by the corpus flag (`ext:<name>`, excluded from the default NASK-only run). Nothing external ships inside the product except, if enabled, derived priors fitted on SHIP-SAFE sources; no page, screenshot or ad creative is redistributed.

**Shipped derived statistics (TRAIN, 2026-11-21):** `hydra/priors/background_df.json.gz` (510 KB, `HYDRA_BACKGROUND_PRIOR`, default `mixed`, `0` = off) holds only truncated sha256 hashes of (gene kind, value) with two unit counts each (legit, fraud); no value, page, screenshot or creative. Derived from (incidents): web-legit-tranco 3,149 (Tranco list 46YVX, Le Pochat et al., "Tranco: A Research-Oriented Top Sites Ranking Hardened Against Manipulation", NDSS 2019; homepages are third-party content, only counts kept), PhreshPhish 1,127 (CC BY 4.0, phreshphish/phreshphish, arXiv 2507.10854), purino-scam-ads 3,408 (card MIT; aggregates only per the lock verdict), phishing-websites-putra 2 (CC BY 4.0, Zenodo 8041387). The file lists these sources and licences in its `sources` field; `scripts/train_prior.py build` refuses any source not marked SHIP-SAFE in `datasets.lock.json`.

## External services (enrichment layer, ADR-007; sources detail in docs/DATA_SOURCES.md)

Only hostnames and IP addresses extracted from the material are sent. No organiser file, image or text leaves the machine. Every response is cached with source, query, timestamp and sha256, so the evaluation can be replayed offline.
